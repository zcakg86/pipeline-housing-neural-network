# H3 Level 9 Model Integration - Complete Guide

## Overview

The V4 model now uses H3 Level 9 hexagons with neighborhood-aware community embeddings. Each property location is represented by its community and the communities of its 6 neighboring hexagons, providing richer spatial context.

## What Changed

### Previous (V3): Single Community Embedding
- Each property → 1 community ID
- Community embedding: `(batch,)` → `(batch, embedding_dim)`
- No spatial context from neighbors

### New (V4): Neighborhood-Aware Embedding
- Each property → 7 community IDs (center + 6 neighbors)
- Community embedding: `(batch, 7)` → `(batch, embedding_dim)`
- Pooled representation captures local spatial patterns

### 3. Pooling Strategies

Three strategies available in `H3CommunityEmbedding`:

**1. Mean Pooling (default)**
```python
pooled = embeds.mean(dim=1)
```
- Simple average of all 7 embeddings
- Equal weight to center and neighbors
- Recommended for initial training

**2. Center-Weighted**
```python
pooled = (center * 0.5) + (neighbors.mean() * 0.5)
```
- 50% weight to exact location
- 50% to neighborhood average
- Good for preserving local specificity

**3. Learnable Weights**
```python
weights = softmax(learnable_params)
pooled = (embeds * weights).sum(dim=1)
```
- Model learns optimal weights
- Most flexible but requires more data
- Can overfit on small datasets

## Backward Compatibility

The code maintains backward compatibility:

1. **If H3 L9 mappings not found:**
   - Falls back to single community index
   - `use_neighborhood_pooling = False`
   - Uses legacy `nn.Embedding`

2. **Loading old V3 models:**
   - Checkpoint doesn't have `use_neighborhood_pooling` key
   - Defaults to `False`
   - Loads as single-index model

3. **Data without h3_09 column:**
   - Warning printed
   - Falls back to legacy community mapping
   - Model still trains but without neighborhood context

## Benefits of H3 L9 Neighborhood Pooling

1. **Higher Spatial Resolution**
   - L9 hexagons: ~0.1 km² (vs L7: ~5.2 km²)
   - More precise location representation

2. **Spatial Context**
   - Captures local neighborhood patterns
   - Smoother predictions across space
   - Better handling of boundary effects

3. **Robustness**
   - Less sensitive to exact hex boundaries
   - Generalizes better to nearby unseen locations
   - Reduces artifacts at community edges

4. **Flexibility**
   - Three pooling strategies to choose from
   - Can experiment with different spatial weighting
   - Learnable weights adapt to data

## Troubleshooting

### Error: "h3_09 column not found"
**Solution:** Your data needs H3 L9 indices. Regenerate with:
```python
import h3
df['h3_09'] = df.apply(lambda row: h3.latlng_to_cell(row['lat'], row['lng'], 9), axis=1)
```

### Error: "h3_l9_neighbor_communities.json not found"
**Solution:** Run precomputation:
```bash
python3 precompute_h3_community_neighbors.py
```

### Warning: "X properties have no H3 L9 neighbor mapping"
**Cause:** Some H3 hexes in your data weren't in the community detection
**Impact:** These properties use UNKNOWN community (index 231)
**Solution:** Acceptable if small percentage (<5%)

### Model trains but attention weights seem off
**Try:**
1. Different pooling strategy (center_weighted vs mean)
2. Adjust learning rate
3. Increase embedding_dim for more capacity
